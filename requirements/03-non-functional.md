# 03. 非機能要件

| 項目 | 要件 |
| --- | --- |
| 対象環境 | iPhone。SwiftUI で作る。iOS 26 以上(リキッドグラスを使う) |
| 位置情報・モーション | 移動の自動判定に使う。初回に理由を説明して、位置情報の「常に許可」とモーション情報の許可を依頼する。理由が明確なら、許可への抵抗はない |
| データ | 端末内にだけ保存する |
| 電池 | 常時の位置追跡を避け、移動を検知したときだけ位置を取って抑える |
| 操作性 | 回答は5秒以内に終わる |
| 判定精度 | 電車と車は区別しにくいので、速度と毎日の経路で判定する。ずれたときは手動で直せる。精度は試作で検証する |
